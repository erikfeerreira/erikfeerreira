## 🚀 Projetos em Destaque

### 🏐 Gaviões na Areia | Plataforma Full Stack de Eventos

Aplicação web desenvolvida para gerenciar inscrições e credenciamento de participantes em eventos esportivos.

**Stack:** React • TypeScript • PostgreSQL • Lovable Cloud

**Principais funcionalidades:**
- Inscrição e gerenciamento de participantes
- Interface responsiva para dispositivos móveis
- Credenciamento e check-in com QR Code dinâmico
- Controle de capacidade com operações atômicas
- Registro de auditoria das operações
- Proteção de dados com Row Level Security (RLS)
- Aplicação de práticas de segurança e privacidade alinhadas à LGPD

**Meu papel:** desenvolvimento e implementação da solução com apoio do Lovable e ferramentas de IA, aplicando conhecimentos de programação, bancos de dados e validação das funcionalidades.

🔗 [Explorar repositório](https://github.com/erikfeerreira/gavioeseventos)

## 🧠 Minha Abordagem com Inteligência Artificial

Utilizo inteligência artificial como ferramenta de apoio ao processo de desenvolvimento, combinando automação com fundamentos técnicos.

Meu fluxo de trabalho envolve:

**1. Planejamento:** definição do problema, requisitos e estrutura da solução.

**2. Desenvolvimento:** construção de funcionalidades com apoio de ferramentas de programação e IA.

**3. Integração:** conexão entre interfaces, APIs, bancos de dados e serviços.

**4. Validação:** revisão de código, testes e correção de problemas.

**5. Evolução:** documentação, manutenção e melhoria contínua.

Ferramentas como **Claude Code, Codex, ChatGPT e Lovable** fazem parte desse processo.

Meu objetivo é desenvolver aplicações cada vez mais confiáveis, organizadas e independentes da ferramenta utilizada.
